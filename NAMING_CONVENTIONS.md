# Project Naming Conventions

## General Rules
- Use lowercase English names.
- Use snake_case for filenames.
- Do not use spaces or special characters.
- Use descriptive names.

## Python Files
Examples:
- player.py
- enemy_ai.py
- asset_manager.py
- quest_system.py

## Image Files
Examples:
- player_idle.png
- player_walk.png
- fireball_attack.png
- boss_death.png

## Audio Files
Examples:
- academy_theme.ogg
- boss_battle.ogg
- player_attack.ogg

## JSON Files
Examples:
- class_data.json
- enemy_data.json
- skill_data.json
- quest_data.json

## Animation Naming
Use the following action names:
- idle
- walk
- attack
- cast
- hit
- dodge
- death

## Character Naming
- ranged_mage
- melee_mage
- balanced_mage

## Asset Rules
- PNG images should use transparent backgrounds when appropriate.
- Sprite sheets should have consistent frame dimensions.
- Keep original asset files.
- Record asset sources and licenses.
